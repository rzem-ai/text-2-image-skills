One model or the whole collection.

Run an install command in your project. Choose your agent interactively, or specify one with --agent codex, --agent claude-code or --agent cursor.

Prefer a file? Every download is a ZIP-format .skill package with an entry point and embedded references. Follow your agent's installation instructions for local skill directories.

List available skills

npx skills add rzem-ai/text-2-image-skills --list

Install every skill for Codex

npx skills add rzem-ai/text-2-image-skills --skill '*' --agent codex --yes

Add --global for a user-wide installation, or --copy to copy files instead of using the CLI's default shared layout.

Prompt guidance, with the details kept close.

These skills help write and refine prompts. They don't run image generation. Capabilities and reference dates are recorded per model; examples are authored suggestions, not rendered benchmarks.
